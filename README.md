# calculator-app

When I started making the calculator app, it was my first real coding experience, and my reason for doing so was to contribute to my personal development and academic advancement. It was a simple beginning, but it helped me understand and grasp the concepts. It includes a settings section where you can choose a theme and view the builder, and a calculator section where you can perform classic mathematical operations. You can also see the calculation history. I will be making a few more apps for CV and will share their executable versions on my website.
